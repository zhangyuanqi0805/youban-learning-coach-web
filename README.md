# 有伴学习空间｜远程学习教练候选

这是独立的公网测试界面。网页视觉参考本地桌面客户端的信息结构，采用有伴青绿色。服务通过 Cloudflare Service Binding 接到已经运行的有伴学生中转，再由中转接入本机总控。仓库仅存界面与代理代码，不存账号、课件、数据库或密钥。

## 开发与部署

- 本地静态预览：`python3 -m http.server 38877 -d public`。本地静态预览不会连接真实后端。
- 公网部署：`wrangler deploy`。需先在 Cloudflare 账户中保留 `youban-student-relay-candidate` Worker。
- 旧公网学生页继续独立运行。新界面使用自己的账号 Cookie，第一次进入须重新登录同一个有伴账号。

## 边界

资料、练习、错题与报告从现有服务读取。学科老师实时问答尚无对应后端接口，页面明确显示为待接入。生成试卷会调用现有受控模型任务，需用户主动点击，结果可能显示等待审核或额度限制。
